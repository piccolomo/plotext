plotext source tree map
=======================

One line per folder and per file, saying what it holds and what it does.
The files under _kernel/cpp are the drawing kernel, written in C++ and compiled into kernel.so when the package is installed.


plotext/                                  the package, holding the figure, the primitives and the tools
    __init__.py                           the names a user reaches, as figure, signal, colorize and file
    __main__.py                           lets the package run as a command, as python -m plotext

    _cli/                                 the plotext command, turning a line of words into a plot
        help.py                           the text printed by plotext --help
        main.py                           where the command starts
        run.py                            runs the methods named on the line, one after the other, with their arguments
        words.py                          reads the words of the line: which name a method, which carry a value

    _constants/                           the fixed values the package is built on, never changed while it runs
        enums.py                          the accepted names: axes, alignments, scales, styles, colors and markers
        numerical.py                      the fixed numbers: sizes, steps, tolerances and bounds
        text.py                           the fixed pieces of text: single characters and short strings

    _correct/                             checks every value a user passes, and puts it in the form the rest of the code expects
        axis.py                           the axis and the side asked for
        bar.py                            the heights, the widths and the shape of the data of a bar plot
        bool.py                           the yes or no values, the direction, the line method and the size policy
        data.py                           the x and y coordinates, made into lists of numbers of the same length
        enums.py                          the names listed in _constants/enums.py, as the effect, the candlestick style and the line style
        heatmap.py                        turns a grid of numbers into a grid of red, green and blue triples
        label.py                          the text of a label, plain, colored or a whole matrix
        limits.py                         the lower and upper bound of an axis
        marker.py                         one marker, or one per point
        matrix.py                         the alignment, the orientation, the slice and the matrix itself
        pixel.py                          a color pair and a style, however they are written
        placement.py                      where a piece of text sits and which way it runs

    _data/                                the sample files shipped with the package, reached by plotext.sample()
        pizzas.csv
        puppy.jpg
        shaq.gif
        stock.csv

    _demos/                               the reference tables printed on demand, as plotext.markers()
        colors.py                         every color: the names, the numbers and the red, green and blue triples
        line_styles.py                    every line style, one box each, with a line across and a line down
        markers.py                        every marker: the named symbols and the higher resolution ones
        styles.py                         every style, each printed in itself
        themes.py                         every theme, as a grid of small plots
        tools.py                          the pieces the demos share: the sizes, the empty row, the title and the note

    _doc/                                 the docstrings of the package, written with prettydoc and reached as plotext.doc
        doc.py                            gathers the sections below into the plotext.doc container
        tools.py                          short names for the prettydoc methods, used by every section
        types.py                          the explanations many docstrings share: what a parameter takes, and the messages that recur

        sections/                         one file per group of methods, holding their docstrings
            01_components.py              the terminal, the figure, and the pieces reached from it: subplot, ruler, date and clear
            02_signal.py                  the signal() method and the methods of the signal itself
            03_point.py                   the point given back by signal.get()
            04_drawing.py                 draw, build, show, interactive and sleep
            05_shapes.py                  rectangle, polygon, segment, line and text
            06_bars.py                    bar, hist and box
            07_specialized.py             candlestick, error, event, heatmap and cmatrix
            08_date.py                    the date methods
            09_media.py                   image, gif and video
            10_settings.py                plot_size, theme and subplots
            11_dressing.py                title, label, axes, canvas and legend
            12_rulers.py                  the ruler methods
            13_clear.py                   the clearing methods
            14_inspection.py              size, parent, master, position, log and time
            15_demo.py                    colors, styles, markers, line_styles and themes
            16_simulate.py                the sin, square and noise generators, and the sample files
            17_terminal.py                the terminal methods
            18_primitives.py              the methods creating each primitive
            19_pixel.py                   the pixel methods
            20_colorize.py                the colorize methods
            21_text.py                    the string tools, uncolorize and effect
            22_matrix.py                  the matrix methods
            23_marker.py                  the marker methods
            24_plotext.py                 the file and prettydoc attributes of the package
            25_file.py                    the file toolkit methods
            26_tools.py                   the matplotlib conversion and the test runner
            27_prettydoc.py               the docs manager and its parts
            28_registry.py                the store of the strings shared by several docstrings

    _kernel/                              the public interface of the package and the bridge to the C++ drawing kernel
        api.py                            the terminal, the master figure and the standalone tools
        clink.py                          declares every function of the kernel, with what it takes and what it gives back
        terminal.py                       the terminal: owns the master figure, reads the terminal size, keeps rows free below the plot and clears the screen
        tools.py                          loads the compiled kernel and registers its functions with the types they use

        cpp/                              the drawing kernel itself, compiled at installation into kernel.so
            00_header.h                   pulls in the standard headers, then every file below in the order they need each other
            01_color.cpp                  color: the code switching the terminal to a foreground or a background color
            02_style.cpp                  style: the code switching the terminal to bold, italic, underline and the rest
            03_pixel.cpp                  pixel: a foreground, a background and a style held together
            04_colorize.cpp               colorize: a piece of text with its pixel, sliced, built and printed
            05_mosaic.cpp                 mosaic: a grid of at most three by three yes or no cells, packed into one byte
            06_character.cpp              character: one drawn cell, plain or built from the higher resolution and box drawing families
            07_matrix.cpp                 matrix: the grid of colored characters a plot is made of, filled, cleared and turned into text
            08_marker.cpp                 marker: the base of everything that can be drawn at a position
            09_position.cpp               position: a pair of coordinates, with the arithmetic turning them into cells
            10_point.cpp                  point: a position carrying its own marker
            11_grid.cpp                   grid: says which point sits in each cell, so a point is found by its column and row
            12_points.cpp                 points: a collection of points
            13_point_filled.cpp           filled point: a point with a second point holding its fill
            14_points_filled.cpp          filled points: a collection of filled points
            15_signal.cpp                 signal: the filled points of one plot, with its axis sides, its label, its marker and how its lines and fills are drawn
            kernel.cpp                    an empty starting point, so the kernel can also be compiled on its own

            utility/                      the general pieces the kernel is built from, needed before anything else
                0_array.cpp               array: a block of values of one type, owning its memory
                10_orientation.cpp        orientation: whether a thing runs across or down
                1_array2d.cpp             array in two dimensions: an array read by column and row, with stacking and inserting
                2_vector.cpp              vector: an array that grows, keeping room ahead of what it holds
                4_constants.cpp           the fixed values of the kernel: the terminal codes and the sizes reserved for the text built
                5_maps.cpp                gathers the three map files below
                6_strings.cpp             the string tools: measuring, converting and writing to the terminal
                7_cstrings.cpp            the same on plain character buffers, for the fastest paths
                8_data.cpp                the number tools: ranges, spacing, the sine wave, sorting, rescaling and bit handling
                9_alignment.cpp           alignment: placing text left, centered or right inside a given width

                maps/                     the tables turning a name into what is drawn or printed
                    high_def.cpp          the higher resolution glyphs, two by two, two by three and two by four, and the box drawing lines
                    marker.cpp            the named symbols and the glyph of each
                    pixel.cpp             the colors both ways, the palette in red, green and blue, the styles, and their form in a web page

    _methods/                             the standalone tools the rest of the package calls, each free of the figure
        bar.py                            the geometry of a bar plot
        effects.py                        the moving text effects, each giving back one colored row
        file.py                           reading, writing, downloading and deleting files
        image.py                          paints a picture or a heatmap straight into a matrix, skipping the signals
        key.py                            says whether a key was pressed, without waiting for one
        matplotlib.py                     walks a matplotlib figure and rebuilds it here
        matrix.py                         joins matrices into larger ones
        object.py                         the small object tools: hashing and type checks
        ruler.py                          the tick tools: how many decimals to write, and how to space and scale the ticks
        sequence.py                       the list tools and the simple number generators
        string.py                         the text tools and the writing to the screen
        subplot.py                        fits the subplots into the space available
        video.py                          plays a video in the terminal, through ffpyplayer

    _plotter/                             the figure: what is drawn on it, how it is dressed, and how it is rendered
        build.py                          renders the final matrix from the signals, the rulers, the axes, the labels, the ticks and the legend
        clear.py                          the clearing methods, gathered so that calling the group clears everything
        draw.py                           the drawing methods: draw and text, the shapes, the bars, and the specialized plots
        legend.py                         the legend: its entries, its position, its colors and its box
        plot.py                           the figure itself, owning its signals, axes, rulers, labels, legend and canvas
        subplot.py                        the grid of panels: how many, how large, and where each one sits

        frame/                            everything around the canvas: the axes, the rulers, their ticks and the labels
            axes.py                       the four axes together, set in one call
            axis.py                       one axis on one side, with its state, its style and its colors
            corner.py                     one of the four corners, with the character it shows
            date.py                       dates: converts between text, date and number, with its own origin and zone
            grid_line.py                  the grid lines of one ruler: their style and whether they are drawn
            labels.py                     the title and the axis labels, with their colors
            limits.py                     the lower and upper bound of one ruler, with its alignment and direction
            line_signal.py                one line across the canvas, with its position on the ruler, its label and how it draws itself
            lines.py                      the lines belonging to one ruler
            ruler.py                      one ruler: its ticks, limits, lines, grid, dates, scale and colors
            rulers.py                     the four rulers together, selected, cleared, copied and updated in one call
            selection.py                  the rulers picked by figure.ruler(): a setting is repeated on each of them, and the picking is given back
            tick.py                       one tick: where it sits and what it says
            ticks.py                      the ticks of one ruler, read, set and rescaled together

        utils/                            the small pieces the figure is built with
            cycler.py                     hands out the colors of a theme in turn, starting again when they run out
            interactive.py                when on, every change to the figure prints it again at once
            part.py                       one region of the plot: its name, its place and its size
            parts.py                      the regions a plot is made of: bars, corners, axes, ticks, canvas and legend
            propagator.py                 the base of the pieces reached from the figure, as the clear object and the rulers
            selection.py                  the base of the objects holding several of one kind, repeating a call on each
            timer.py                      times each step of the rendering, for figure.time()

    _primitives/                          the objects a plot is made of, each usable on its own
        box.py                            the line drawing characters and their crossings, as ├ or ┼, each arm set apart
        box_style.py                      the style and colors a box is drawn with
        colorize.py                       a piece of text with its colors, stacked, sliced and printed
        marker.py                         the symbol drawn at each point, with its colors
        matrix.py                         the grid of colored characters, filled, stacked, sliced and saved
        pixel.py                          a foreground color, a background color and a style

    _settings/                            the values the package starts with, and the themes
        defaults.py                       every default: the terminal size, the colors, the markers, the legend, the subplots and the rest
        system.py                         the system in use, the package version, and the optional packages
        themes.py                         the named themes: the colors of the canvas, axes, ruler, label and legend, and the sequence given to the signals

    _signal/                              the data of a plot: its points and the look chosen for them
        grid.py                           the fixed grid used to find a point by its column and row
        point.py                          one point with its marker
        point_filled.py                   one point with its fill
        points.py                         the points of a signal, appended, moved, picked and squashed into cells
        signal.py                         the signal: its points, its fills, its axis sides, its label and its marker
        signals.py                        the signals of a figure, with their overall limits

    _tests/                               the test suite run by plotext.test()
        dates.py                          the three ways of writing a date, and the settings holding them together
        fixed_bugs.py                     one test per bug already fixed, so that none of them comes back
        hashes.py                         six whole plots frozen by their hash, to catch a change nobody meant to make
        plots.py                          the built plot, asked questions rather than compared with a picture
        primitives.py                     the primitives on exact values: pixel colors, matrix positions and sizes, colorize widths
        run.py                            runs every test file beside this one

    prettydoc/                            the builder of the colored docstrings, used by the whole package

        _defaults/                        the values prettydoc starts with
            pixels.py                     the colors of each part of a docstring: the title, the alias, the parameters and the output

        _demos/                           the reference table prettydoc prints on demand
            demo.py                       every part of a docstring, and what each one looks like

        _menu/                            the pieces the interactive menu is drawn with
            keys.py                       reads one key at a time, and puts the terminal where each key arrives at once
            layout.py                     the sizes of the menu: the columns, the cells, the lines and the headers
            text.py                       measures and wraps colored text, so a docstring fits its column

        _methods/                         what the user of prettydoc calls
            menu.py                       the menu: the sections, the methods of the picked one, and its docstring, side by side

        _primitives/                      the objects a documentation is made of
            container.py                  what update() gives back: one printing method per entry, reached by name
            docs.py                       the manager: registers every function with its documentation and builds the container
            function.py                   one entry: the function it describes, its description and its parameters
            parameter.py                  one parameter, or one output: its name, its description, its type and its default
            registry.py                   the store of the strings shared by several docstrings
            source.py                     one step along the dotted path, as the pixel in plotext.doc.pixel.copy()
            text.py                       the pieces of text a docstring is built from: a plain piece, the alias line, and a label with its value

        _tests/                           the test suite run by plotext.prettydoc.test()
            docs.py                       the built docstring, asked what it says
            hashes.py                     a whole docstring frozen by its hash, to catch a change nobody meant to make
            run.py                        runs every test file beside this one
