plotext source tree map
=======================

One line per file, taken from the opening comment of the file itself, so that the map and the code cannot drift apart.
The files under _kernel/cpp are the drawing kernel, written in C++ and compiled into kernel.so when the package is installed.


plotext/
    __init__.py                           package entry point, exposing the public names: figure, signal, draw, file, the primitives and the tools
    __main__.py                           lets the package run as a command, as in python -m plotext

    _cli/
        help.py                           --help output: styled headers and categorized usage hints
        main.py                           command-line entry point
        run.py                            takes the (method, arguments) tuples built by words.py and runs them in order: finds each method, turns its arguments ...
        words.py                          everything about the words of the sentence: which ones name a method, and what value each one carries

    _constants/
        enums.py                          enum-style constants: named sets of allowed values for axes, alignment, scales, styles, colors and markers
        numerical.py                      numerical constants: discrete sets, deltas, tolerances and bounds
        text.py                           text constants: single-character and short string literals used across rendering and formatting

    _correct/
        axis.py                           axis validation and normalization utilities
        bar.py                            validation utilities for bar-plot parameters and data shapes
        bool.py                           validation utilities for boolean and binary flag parameters: booleans, directions, line methods, size policies
        data.py                           data formatting utilities for x/y inputs and list normalization
        enums.py                          validation utilities for the names listed in _constants/enums.py: effect, candlestick style and line style
        heatmap.py                        convert a 2D grid of numbers into a 2D of (r, g, b) triples for heatmap rendering
        label.py                          label normalization and formatting utilities
        limits.py                         limits validation and normalization utilities
        marker.py                         marker normalization utilities: single marker and repeated marker lists
        matrix.py                         alignment, orientation, slice and matrix normalization utilities
        pixel.py                          pixel normalization utilities
        placement.py                      validation utilities for placement parameters (alignment and orientation)

    _data/
        pizzas.csv
        puppy.jpg
        shaq.gif
        stock.csv

    _demos/
        colors.py                         the colors demo: the string codes, the integer codes and the rgb tuples
        line_styles.py                    the line styles demo: one box per style, with a middle horizontal and vertical line
        markers.py                        the markers demo: the named character codes and the higher resolution ones
        styles.py                         the styles demo: every style code printed in its own style
        themes.py                         the themes demo: a grid of mini plots, one per theme
        tools.py                          the pieces shared by the demos: the layout sizes, the blank row, the bold title and the note

    _doc/
        doc.py                            aggregator: each section file registers its docstrings via the shared prettydoc manager from tools.py; this module ...
        tools.py                          short names for the prettydoc methods, used by every section file
        types.py                          the explanations shared by many docstrings: the value each parameter takes, and the recurring messages

        sections/
            01_components.py              plot components section: terminal, figure and the figure component getters (subplot, ruler, date, clear)
            02_signal.py                  signal section: the signal creation method and the signal object methods
            03_point.py                   point section: the point returned by signal.get()
            04_drawing.py                 drawing and rendering section: draw, build, show, interactive and sleep
            05_shapes.py                  shapes and text section: rectangle, polygon, segment, line and text signals
            06_bars.py                    bar plots section: bar, hist and box signals
            07_specialized.py             specialized plots section: candlestick, error, event, heatmap and cmatrix signals
            08_date.py                    date section: the date converter methods
            09_media.py                   media section: image, gif and video
            10_settings.py                settings section: plot_size, theme and subplots
            11_dressing.py                plot dressing section: title, label, axes, canvas and legend
            12_rulers.py                  rulers section: the ruler methods
            13_clear.py                   clear section: the clearing methods
            14_inspection.py              plot inspection section: size, parent, master, position, log and time
            15_demo.py                    demo section: colors, styles, markers, line_styles and themes reference printers
            16_simulate.py                simulate section: the sin, square and noise data generators, plus the bundled sample files
            17_terminal.py                terminal section: the terminal methods
            18_primitives.py              primitives section: the creation methods of every plotext primitive
            19_pixel.py                   pixel section: the pixel object methods
            20_colorize.py                colorize section: the colorize object methods
            21_text.py                    text section: the string tools (uncolorize, effect)
            22_matrix.py                  matrix section: the matrix object methods
            23_marker.py                  marker section: the marker object methods
            24_plotext.py                 plotext components section: the file and prettydoc attributes (doc joins from the aggregator)
            25_file.py                    file section: the file toolkit methods
            26_tools.py                   tools section: matplotlib conversion and the test runner
            27_prettydoc.py               prettydoc section: the docs manager and its members
            28_registry.py                registry section: the store of strings shared by several docstrings

    _kernel/
        api.py                            public API: the terminal, the master figure, and a handful of standalone helpers
        clink.py                          registration of all C kernel bindings: declares input and output types for every exported function
        terminal.py                       terminal: owns the master plot, tracks the terminal size and prompt height, and clears the screen
        tools.py                          bridge to the C kernel: loads the compiled library and registers each of its functions with the types it takes and ...

        cpp/
            00_header.h                   aggregator header: pulls in standard library headers and then concatenates every kernel source file in dependency order
            01_color.cpp                  color: stores the ANSI escape sequence for a foreground or background color; base class for Fullground and Background
            02_style.cpp                  style: stores the ANSI escape sequence for one or more text styles (bold, underline, italic, etc.)
            03_pixel.cpp                  pixel: composite of Fullground, Background and Style used as the color/style carrier throughout the kernel
            04_colorize.cpp               colorize: wide string paired with a Pixel (color + style); supports slicing, buffered rendering and printing
            05_mosaic.cpp                 mosaic: a boolean matrix of at most 3 by 3, packed into one byte, the top left cell taking the highest bit
            06_character.cpp              character family: NormalCharacter (Pixel + wchar), 4 X-Character builders (HD/FHD/Braille/Box) holding bits, ...
            07_matrix.cpp                 matrix: a grid of MatrixCharacter cells, built, filled, cleared and rendered here; the insert paths of Point, Points, ...
            08_marker.cpp                 marker: abstract polymorphic base for things you can plot at a position
            09_position.cpp               position: lightweight 2D float position with fast integer conversion and marker-cell helpers
            10_point.cpp                  point: a 2D position (inherits Position) carrying an OWNED Marker (deep-copied via Marker::copy on construction/copy)
            11_grid.cpp                   grid: 2D grid mapping (col, row) → point index in some Points collection
            12_points.cpp                 points: a collection of Point built on top of plotext's Vector
            13_point_filled.cpp           filledPoint: a Point with a companion "fill" Point
            14_points_filled.cpp          filledPoints: a collection of FilledPoint built on Vector
            15_signal.cpp                 signal: a FilledPoints with plotting metadata (xside/yside, label, marker, fill_method, line_method)
            kernel.cpp                    standalone entry point, empty: the kernel is used as a library, and this main() only exists so it can also be compiled ...

            utility/
                0_array.cpp               array: owning dynamic-length buffer used throughout the kernel
                10_orientation.cpp        orientation: horizontal / vertical layout direction for text and similar drawables
                1_array2d.cpp             array2D: 2D wrapper around Array<T> with (col, row) access and stack/insert helpers
                2_vector.cpp              vector: dynamic-length container built on top of Array (capacity vs logical length)
                4_constants.cpp           kernel-wide constants: ANSI escape sequences and pre-computed upper-bound buffer sizes
                5_maps.cpp                kernel maps aggregator: pixel-level lookups (color/style/HTML), normal marker lookups, and high-definition marker + ...
                6_strings.cpp             utility functions for string manipulation, encoding conversion and console output
                7_cstrings.cpp            c-style wide string and buffer utilities (raw wchar_t* operations and append-to-buffer helpers)
                8_data.cpp                data utilities: range/linspace/sin_wave/sort/rescale helpers, plus bit manipulation and the C rescale wrapper
                9_alignment.cpp           alignment utilities: left/center/right anchoring used when placing text inside fixed-width cells

                maps/
                    high_def.cpp          high-definition marker maps: HD (2x2), FHD (2x3), Braille (2x4) glyph lookups and Box-drawing line lookups
                    marker.cpp            normal marker maps: symbol name -> glyph, marker-kind tags, representative glyph per kind
                    pixel.cpp             pixel-level maps: color name <-> code, palette index -> RGB, style name -> code, style code -> CSS fragment

    _methods/
        bar.py                            bar plot geometry helpers
        effects.py                        step-driven text effects: a single dispatcher that returns a styled 1-row matrix
        file.py                           internal file I/O implementation
        image.py                          direct heatmap / image painters: produce a fully-coloured plotext.matrix without going through the signal pipeline
        key.py                            non-blocking key polling: returns True if the user has pressed `key` since the last call
        matplotlib.py                     structural converter: walks a matplotlib Figure (subplot grid, axes, lines, scatters, patches) and rebuilds it onto ...
        matrix.py                         utilities to join and compose matrix instances into larger matrices
        object.py                         object utilities: hashing and type checks
        ruler.py                          ruler utilities for tick formatting, scaling, and numeric precision
        sequence.py                       sequence utilities for list operations and basic numerical generation
        string.py                         string utilities and stdout helpers for rendering and formatting
        subplot.py                        utilities for fitting and distributing subplot sizes within constraints
        video.py                          terminal video playback via ffpyplayer

    _plotter/
        build.py                          build: renders the final plot matrix from signals, rulers, axes, labels, ticks, legend and corners
        clear.py                          clear component: groups the figure clearing methods; calling the component itself clears everything, like all()
        draw.py                           the drawing methods of the figure: draw and text, the shapes line, rectangle and polygon, the bars bar, hist and box, ...
        legend.py                         legend component for plotext: manages markers, labels, pixel, position and frame
        plot.py                           plot class: main subplot container with signals, axes, legend, rulers, labels and canvas
        subplot.py                        subplot class: manages subplot grid, sizes and positions

        frame/
            axes.py                       axes: 2x2 container of frame axes (x lower/upper, y left/right) with batch operations
            axis.py                       axis: single frame axis (one axis / one side), with status, style and pixel
            corner.py                     corner: one of the four frame corners (lower-left, lower-right, upper-left, upper-right) with its tick symbol
            date.py                       date: converts between string, datetime and timestamp representations with a configurable origin
            grid_line.py                  grid line: ruler-local box_style + active flag
            labels.py                     labels container: title plus x/y labels with pixel styling
            limits.py                     limits: ruler lower/upper bounds with alignment and direction
            line_signal.py                line signal: a line with a position on its ruler, a label and a way to draw itself on the canvas, using the limits of ...
            lines.py                      lines: lightweight container of line_signal entries owned by a ruler
            ruler.py                      ruler: one axis/side ruler owning ticks, limits, lines, grid, date, scale and pixel
            rulers.py                     rulers container: manages 2x2 X/Y rulers, selection, clearing, cloning, updates
            selection.py                  ruler and date selections: returned by figure.ruler(axis, side); setters repeat on every selected item and chain, ...
            tick.py                       tick: single ruler tick with a position and a label
            ticks.py                      ticks: container of tick_class instances with batch get/set/rescale operations

        utils/
            cycler.py                     a utility class to cycle through a predefined sequence of pixels
            interactive.py                interactive mode: with it on, every method changing the figure reprints it as soon as it ends, so the plot updates as ...
            part.py                       this module defines a `part` class that represents a part with a name, position, and size
            parts.py                      parts container: owns the named regions (bars, corners, axes, ticks, canvas, legend) that make up a plot layout
            propagator.py                 propagator: the base of the plot components reachable from the figure, like the clear object and the rulers; it holds ...
            selection.py                  selection: base for objects holding several same-kind items (rulers, date converters); repeats a method on every item
            timer.py                      timer: lightweight event timer used to profile build steps (start/stop per label, accumulated elapsed time and counter)

    _primitives/
        box.py                            box primitive: the characters drawing lines and their crossings, as ├ or ┼; box_class takes each arm on its own, used ...
        box_style.py                      boxStyle primitive: thin wrapper around C++ BoxStyle (style + pixel; no arms, no active flag)
        colorize.py                       colorized string object with pixel-based styling and matrix operations
        marker.py                         marker primitive: wraps a C++ marker pointer; handles normal/typed markers and exposes model, pixel and string
        matrix.py                         matrix primitive: wraps C++ matrix pointer; supports pixels, insertion, stacking and slicing
        pixel.py                          pixel primitive handling using clink bindings

    _settings/
        defaults.py                       default settings: terminal size, axis/grid/colors/pixels, subplot, legend, marker and miscellaneous defaults
        system.py                         system settings: the system in use, the package version, and the optional packages, imported here and left as None when ...
        themes.py                         the named color themes: each holds the pixels of the canvas, axes, ruler, label and legend, plus the sequence given to ...

    _signal/
        grid.py                           grid: fixed-size (cols x rows) backing grid used by points_class.squash for fast (col, row) → point-index lookup
        point.py                          point: single (x, y) position with a marker, backed by the C kernel
        point_filled.py                   pointFilled: single filled data point with x/y/col/row, marker and foreground color, backed by the C kernel
        points.py                         points: container of data points backed by the C kernel; supports appending, offsetting, selection and squashing
        signal.py                         signal class: wraps C++ signal pointer; manages points, fill, axes, labels and plotting
        signals.py                        signals container: holds a list of signal objects, with aggregated limits and selection

    _tests/
        dates.py                          tests of date support: the three ways of writing a date, and the settings holding them together
        fixed_bugs.py                     one test per bug already fixed, so that none of them comes back
        hashes.py                         six whole plots frozen by their hash, to catch a change nobody meant to make
        plots.py                          tests of the built plot, asking questions of the result rather than comparing pictures
        primitives.py                     tests of the primitives, on exact values: pixel colors, matrix positions and sizes, colorize widths
        run.py                            runner of the plotext test suite, gathering the tests of every module beside this one
