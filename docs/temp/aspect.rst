Plot Aspect
===========

Plot Labels
-----------

To add text labels to the plot, use the ``label`` parameter of the following methods:

- ``title()`` to add a **title** at the top of the active plot.

.. - ``xlabel()`` to add the **x-axis labels**. Its parameter ``xside`` specifies which x-axis to target: ``lower`` or ``upper`` (short: ``1`` or ``2``).

.. - Similarly, ``ylabel()`` adds **y-axis labels**. Its parameter ``yside`` specifies which y-axis: ``left`` or ``right`` (short: ``1`` or ``2``).

.. - All axis labels appear at the bottom of the plot, except for the upper x-axis label, which appears at the top center. If a plot title is present, it is moved to the top left.

.. - To change label colors and styles, use the functions ``ticks_colors()`` and ``ticks_style()``, as explained in the `Colors section <https://github.com/piccolomo/plotext/blob/master/readme/aspect.md#colors>`_ and `Styles section <https://github.com/piccolomo/plotext/blob/master/readme/aspect.md#styles>`_ respectively.

.. See also: `Main Guide <https://github.com/piccolomo/plotext#guide>`_, `Plot Aspect <https://github.com/piccolomo/plotext/blob/master/readme/aspect.md#plot-aspect>`_.
