Demo
----

- `plotext.colors()` displays the available color codes.

- `plotext.styles()` displays the available style codes.


Testing Tools
-------------

- `plotext.test()` performs unit tests for the `plotext` package.

- `plotext.prettydoc.test()` performs unit tests for the `prettydoc` module.


NotSureYet Tools
----------------

- `plotext.sin()` generates a **sinusoidal signal** with the specified `periods`, `length`, and `amplitude`. More documentation is available in the `plotext.doc.sin()` method and the :func:`plotext.sin` API reference.
