Similar Projects
----------------

These count as well as sources of inspiration:

- `plotille <https://github.com/tammoippen/plotille>`_: plots, scatter plots, histograms and heatmaps, drawn with braille dots
- `termplot <https://github.com/justnoise/termplot>`_: simple line plots and histograms
- `termgraph <https://github.com/sgeisler/termgraph>`_: candlestick graphs, drawn with box characters
- `terminalplot <https://github.com/kressi/terminalplot>`_: minimal scatter plots, with no dependencies
- `asciichart <https://github.com/cashlo/asciichart>`_: simple ascii line charts
- `uniplot <https://github.com/olavolav/uniplot>`_: lightweight plotting, with four times the resolution through Unicode
- `bashplotlib <https://github.com/glamp/bashplotlib>`_: basic plots directly from the shell
- `termplotlib <https://github.com/nschloe/termplotlib>`_: plots and histograms with a matplotlib-like interface
